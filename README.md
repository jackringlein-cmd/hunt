# The Hunt for the Necromancer

A browser tower defense game created with Jack.

Play in Safari on iPad or a desktop browser. Touch devices start with the mobile layout. Change layouts using Version in the main menu. Each map saves progress separately in the current browser.

## Run locally

Install Node.js, then run `node server.js` and open http://127.0.0.1:4173/.

## GitHub Pages

Publish from the main branch, root folder, in this repository's Settings > Pages.
